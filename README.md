# ESP32 Local WiFi Server

Proyecto basado en **ESP32** que implementa un servidor web local accesible vía WiFi.  
Permite controlar y visualizar información desde cualquier dispositivo conectado a la misma red.

## ✨ Características
- Configuración de red WiFi en modo estación (STA).
- Servidor HTTP básico para atender peticiones GET/POST.
- Página web embebida para interacción con el usuario.
- Ejemplo de control de GPIO (encendido/apagado de LED).
- Código modular y fácil de extender.

## 🔧 Requisitos
- Placa ESP32 (ej. ESP‑32S DevKit).
- Entorno de desarrollo ESP‑IDF o Arduino IDE.
- Conexión WiFi disponible.

## 🚀 Uso
1. Compilar y flashear el firmware en el ESP32.
2. Conectar el dispositivo a la red WiFi configurada.
3. Acceder desde el navegador a la IP asignada por el router.
